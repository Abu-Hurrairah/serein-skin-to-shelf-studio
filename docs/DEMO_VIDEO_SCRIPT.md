# Serein — 2:15 demo plan (record your own desktop screen + voice)

**00:00–00:20 — The problem**
"Skincare shopping is overwhelming. People buy more products than they need, without understanding which cosmetic concerns to prioritise. Serein is a skin-to-shelf decision studio built to change that."

**00:20–00:42 — Show Overview & Scan**
"The journey starts with a photo, not a sales pitch. A user can upload a well-lit selfie or take one with the camera. In live mode, the user explicitly consents before the photo is sent to the YouCam Skin Analysis API."

**00:42–01:10 — Explain actual technical integration**
"Our FastAPI backend calls Perfect Corp's File API, uploads the picture to the signed storage URL, starts a Skin Analysis v2.1 task, then polls until the analysis returns. The UI only displays scores supplied by YouCam." 

If your API key **is not configured**, say instead: "I'm showing the labelled example experience here, using illustrative sample scores. The real YouCam integration is in the backend and becomes active with a key." Do not claim to be showing a live scan.

**01:10–01:32 — Insights**
"Serein turns these appearance indicators into a simple overview. The lower-scoring areas appear first, with plain-English explanations and clear cosmetic-only disclaimers."

**01:32–01:57 — Ritual & retail value**
"Instead of recommending an endless shelf, we start with cleansing, moisturising and SPF and cap optional recommendations at two. You can see why each category was suggested, remove items, and adjust an illustrative budget tier. Nothing here is a product advertisement."

**01:57–02:15 — Journal & closing**
"The journal lets users reflect on changes over time. Only metrics and notes are kept in local browser storage, not their photos. Serein helps shoppers ask a better question: Do I actually need this?"
